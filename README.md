## 🚀 Descripción

Este proyecto consiste en el desarrollo de un **agente inteligente** capaz de analizar documentos PDF y responder preguntas del usuario en lenguaje natural.

El sistema permite interactuar con la información contenida en el documento, simulando el comportamiento de un asistente conversacional.

---

## 🧠 Funcionalidades

✔ Lectura de documentos PDF  
✔ Procesamiento de texto  
✔ Interacción tipo chat  
✔ Respuestas automáticas  
✔ Ejecución en entorno local y cloud  

---

## 🛠️ Tecnologías utilizadas

- Python 🐍  
- PyPDF 📄  
- Streamlit (opcional) 🌐  
- Oracle Cloud Infrastructure ☁️
